# Honestly Texas — Shopify theme

Custom Shopify theme for **Honestly Texas Rice** (`honestlytexasrice.myshopify.com`), built from the Figma file *Honestly Texas* (Shopify Homepage Round 2 — "Good rice. Texas roots.").

## Structure

Standard Shopify Online Store 2.0 theme: `layout/`, `sections/`, `snippets/`, `templates/` (JSON), `config/`, `locales/`, `assets/`.

## Workflow

This repo is connected to the store through the Shopify GitHub integration. Commits to `main` sync to the connected theme; edits in the theme editor commit back here.

## Notes

- Fonts: Archivo Black + DM Sans (temporary substitutes per the Figma notes).
- Section images use image pickers — upload final photography in the theme editor.
- Prices, stock and shipping always come from Shopify; no invented offers.
